# Sistema Predictivo de Demanda 

 

## Descripción 

 

Proyecto académico de Machine Learning y MLOps para 

estimar la demanda del día siguiente utilizando 

información empresarial relacionada con ventas, 

inventario, marketing, canal, producto y otras variables. 

 

## Componentes 

 

- Modelo predictivo entrenado. 

- Pipeline de preprocesamiento. 

- Aplicación Streamlit. 

- Archivo requirements.txt. 

- Metadata del modelo. 

- Resultados de evaluación. 

- Evidencia de monitoreo. 

 

## Variable objetivo 

 

Demanda_Dia_Siguiente 

 

## Ejecución local 

 

Instalar dependencias: 

 

pip install -r requirements.txt 

 

Ejecutar aplicación: 

 

streamlit run app.py 

 

## Uso responsable 

 

La predicción debe utilizarse como apoyo a la toma 

de decisiones y no como sustituto absoluto del juicio 

profesional. 

 

Debe monitorearse periódicamente el desempeño, 

la calidad de los datos y posibles cambios en la 

distribución de las variables.
